# Support de cours Java (1998)

👉 **Cours original (1998)** :
[https://stahe.github.io/java-sept-1998/](https://stahe.github.io/java-sept-1998/)

---

## Introduction

Ce document constitue un **support de cours** et non un cours complet.
Certains approfondissements nécessitent l’accompagnement d’un enseignant.

Cependant, l’étudiant y trouvera une quantité importante d’informations lui permettant, dans la plupart des cas, de travailler en autonomie.

---

## Ouvrages recommandés

Il existe d’excellents livres sur Java. Parmi eux :

1. **Programmer en Java**
   Claude Delannoy – Éditions Eyrolles

2. **Java client-serveur**
   Cédric Nicolas, Christophe Avare, Frédéric Najman – Eyrolles

Le premier ouvrage constitue une excellente introduction pédagogique au langage Java.
Une fois son contenu maîtrisé, le second permet d’aborder des aspects plus avancés :

* Java Beans
* JDBC
* CORBA / RMI

Il propose également une vision industrielle de Java.

Pour approfondir Java dans différents domaines, la collection **"Java Series"** chez O’Reilly constitue une référence intéressante.

Pour une utilisation professionnelle de Java au sein d’une plate-forme J2EE :

3. **Programmation J2EE**
   Éditions Wrox (distribué par Eyrolles)

## Avertissement

Lors de la rédaction initiale de ce cours (1998), l’auteur maîtrisait imparfaitement les conventions d’écriture du code Java.

À cette époque :

* Le langage était encore récent.
* Aucun IDE n’était utilisé pour signaler les infractions aux conventions de nommage.

En conséquence :

* Les noms de classes et d’interfaces devraient commencer par une majuscule.
* Cette règle n’est pas systématiquement respectée dans le document.

Par ailleurs, plusieurs technologies présentées sont aujourd’hui obsolètes :

* RMI
* CORBA
* Swing
* Applets
* L’IDE JBuilder

Plutôt que de réécrire ce document, un nouveau cours a été rédigé en 2015 :

👉 **Introduction au langage Java et à l’écosystème Spring au travers d’une étude de cas (2015)** : 
[https://stahe.github.io/java-spring-dec-2015/](https://stahe.github.io/java-spring-dec-2015/)

Ce nouveau cours s’appuie partiellement sur certains chapitres du présent document.

Il est recommandé d’utiliser en priorité le cours de 2015 et de consulter celui-ci uniquement lorsqu’il y est fait référence.
